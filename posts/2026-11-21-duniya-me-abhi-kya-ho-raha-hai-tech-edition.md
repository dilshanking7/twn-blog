# Duniya me abhi kya ho raha hai — tech edition

Language: English | Date: 2026-11-21 | Provider: gemini

I spent part of last weekend trying to run an 8-billion parameter model locally on my laptop. Two years ago, that sentence wouldn't have made sense unless you had access to a university cluster or a very expensive cloud setup. Today, tools like Ollama and quantized models mean a student in Dhanbad can run a functional language model offline without paying API fees to OpenAI.

That shift sums up what is happening in global tech right now. The initial shock of generative AI has passed, and we are now in the infrastructure and optimization phase. Companies are realizing that sending every small database query or text summarization request to a massive cloud endpoint is financially unsustainable. Open-weight models like Meta’s Llama 3 and DeepSeek’s recent releases have proven that smaller, specialized models trained on cleaner data can match older systems while running at a fraction of the hardware cost.

On the hardware front, the struggle for silicon is moving closer to home. Nvidia is still driving the high-end server market, but the physical bottlenecks in global supply chains are forcing countries to build their own capacity. India has finally started ground work on major semiconductor facilities, including Tata’s fab in Dholera, Gujarat, and assembly plants in Assam. It will take years before these fabs output high-end processors, but the shift from pure software outsourcing to chip design and local assembly is already visible in university curricula and hardware startups.

For software developers, especially those of us still studying or looking for entry-level roles, the hiring market looks noticeably different than it did three years ago. The wave of indiscriminate hiring for junior frontend developers has ended. Big tech companies and Indian startups alike have slowed down general hiring to balance their sheets after the post-pandemic expansion.

Instead, the industry is demanding deeper technical fundamentals. Building a basic React app with a Firebase backend doesn't stand out anymore when automated tools can generate that boilerplate in seconds. The developers getting hired right now are the ones who understand system design, memory management, networking primitives, database indexing, and how to write efficient code in languages like Go or Rust.

Speaking of web development, there is clear fatigue growing around hyper-complicated JavaScript frameworks. For years, the trend was to add layers of abstraction—complex build pipelines, serverless edge functions, and frameworks that changed their routing paradigms every year. Now, developers are stepping back. Lightweight alternatives like Hono, simple server-rendered setups, and embedded databases like SQLite are dominating developer discussions on GitHub and tech forums.

Self-hosting is also seeing a revival. Developers are turning away from managed platforms for side projects and going back to basic Linux servers on providers like Hetzner or DigitalOcean. Dockerizing an application and running it on a $5 monthly virtual private server is common again, mostly because developers are tired of vendor lock-in and surprise cloud billing statements.

Out here in Dhanbad, away from the noise of tech hubs like Bengaluru or Hyderabad, it is easy to feel overwhelmed by the constant stream of new tools and releases. But if you strip away the marketing posts on Twitter and LinkedIn, the direction is straightforward. Tech is becoming leaner, lower-level, and much more cost-conscious. The initial hype cycle has settled, and the actual engineering work has begun.
